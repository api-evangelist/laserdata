# LaserData

> LaserData is a hyper-efficient data streaming platform built for AI-native, real-time, and latency-sensitive workloads.

LaserData provides managed, BYOC, and on-premise deployment models powered by Apache Iggy. This file highlights the most useful pages for understanding the product, its architecture, and how to get started.
